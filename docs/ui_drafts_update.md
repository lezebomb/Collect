# Dearshelf 界面与草稿更新

日期：2026-10-01。名称与南瓜猫图标先独立留档并推送：`33a23606897dc7e9441e8dfbf89edbd5a0d005c8`。本轮基于该版本继续修改。

## 界面与交互

- 展柜左上角显示 **Dearshelf**，保留紧凑收藏墙、完整名称自适应、圆润卡片、搜索和排序交互。
- 统计保留“收藏统计”，删除顶部两句宣传文案；分类和年份分别通过右上角分类、日历图标打开圆角选项面板。选中的筛选范围显示为轻量文字。
- 摘要改为“藏品价值”“藏品数量”。每个条形统计区域内使用不同颜色，区域之间复用同一套柔和配色。
- 月度消费趋势改为曲线；纵轴固定展示 CNY 金额，曲线、月份与对应金额横向一起滚动，覆盖完整年份范围，未购入月份显示 0。初始定位最近购入月份，不再截断历史为最后 12 个有消费的月份。
- 设置移除“让展柜更像你”及壁纸功能入口；展柜也不再展示旧壁纸。旧壁纸字段与备份兼容处理保留，未删除云端历史数据。
- 收藏分类使用圆圈、三角、方块、叉四种手柄符号，占用原来的 20px 图标位置。减号在加号左侧，点击进入删除模式，分类末尾才显示叉号；点击空白区域或再次点击减号退出。默认分类与自定义分类使用同一组件；删除分类不影响已有收藏。
- 退出登录先显示“确认要退出登录吗”，选择“确认”才调用现有退出流程；取消不退出。避免重复打开确认对话框。
- “展示每天花费”改为“展示日均价格”。首页价格形式支持原币种与 CNY 折算，同时应用于价格和日均价格。CNY 采用收藏中已有的折算金额；旧外币记录没有折算值时提示未折算，不将原币金额冒充 CNY。
- 添加与编辑页面将“描述 / 故事”改为“简介”；编辑提交文案改为“保存修改”。搜索选择仍保持图片、名称两个独立选项，不自动填入简介。
- 导出、导入、保存草稿、保存修改、删除收藏、登录、注册、发送重置邮件与修改密码等操作使用对应的等待提示。未改变搜索、OCR、汇率或密码恢复业务流程。

## 草稿与返回

- 空白添加页面直接返回；有改动时提示“是否要保存至草稿箱”，提供“保存”“不保存”。关闭对话框则留在页面。
- 每个账号在本机保留一份添加草稿，包含简介、分类、游戏字段、购入日期、原币价格、折算金额和封面字节。再次添加自动恢复；退出或重新启动后仍可读取，不依赖相册选择器的临时路径。
- “不保存”丢弃当前添加草稿；成功创建收藏后清空草稿。磁盘写入失败时保留当前页面及上一份已成功保存的草稿。
- 编辑已有收藏只比较表单改动，不恢复添加草稿。返回时提示“是否保存修改”；保存调用现有更新流程并等待完成后退出，不保存则返回原记录。验证不通过或网络保存失败时留在编辑页面。
- 工具栏返回键与 Android 系统返回键都经过同一确认流程；保存和退出过程防止重复提交或重复弹窗。

## 数据与性能范围

- 数据库、迁移、已有 models / repositories、统计计算与 ZIP / JSON 备份格式均未修改。价格展示偏好和草稿仅保存在本机，按账号隔离，不纳入旧格式云端备份或跨设备同步。
- 本地文件先完整写入临时文件并 flush，再替换正式文件，失败不覆盖上一份草稿。
- 原有 IndexedStack、Signed URL 会话缓存、图片缓存、设置开关乐观更新继续保留。本轮不在卡片绘制、曲线滚动或 Tab 切换时新增网络查询。
- 月度曲线使用 CustomPainter 与 RepaintBoundary；没有引入图表库或额外动画控制器。数据不变时保留曲线滑动位置，筛选改变后定位最近月份。
- `path_provider 2.1.6` 从已有间接依赖改为直接依赖，用于应用私有目录；锁文件中的版本及其依赖未升级，没有引入新包。
