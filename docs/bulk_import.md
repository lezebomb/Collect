# 批量导入藏品清单

在手机上进入 **设置 → 批量导入藏品 → 下载清单模板**，保存模板后，用支持 UTF-8 的文本编辑器填写。扩展名保留 `.json`。也可以从仓库的 `docs/templates/dearshelf-item-list.json` 复制模板。

填写好后，把文件放进手机的“下载”文件夹。在 **选择清单文件导入** 中，选择一个文件，或长按后勾选多个文件，再点击“打开”。App 会检查所有选中文件，显示文件数量和藏品数量；确认后才新增藏品。所有文件合计每次最多 500 件，单个文件最多 5 MB。

```json
{
  "format": "dearshelf-item-list",
  "version": 1,
  "items": [
    {
      "name": "我的 PC 游戏",
      "category": "游戏",
      "description": "和朋友一起通关的回忆。",
      "purchase_date": "2026-10-03",
      "price": 68,
      "currency": "CNY",
      "game_platform": "PC",
      "game_content_type": "本体",
      "game_play_status": "游玩中"
    },
    {
      "name": "旅行纪念品",
      "category": "纪念品"
    }
  ]
}
```

每个 `{ ... }` 代表一件藏品，各件之间用逗号分隔。字段名、文本用英文双引号；金额直接写数字，不加货币符号，也不要加千位逗号。JSON 不支持注释，也不能在最后一项后面多加逗号。

| 字段 | 必填 | 填法 |
| --- | --- | --- |
| `name` | 是 | 藏品名称，最多 120 个字 |
| `category` | 是 | 分类名称，最多 60 个字；新分类会加入设置中的选项 |
| `description` | 否 | 简介，最多 10000 个字 |
| `purchase_date` | 否 | `YYYY-MM-DD`，例如 `2026-10-03`；范围与添加页面相同 |
| `price` | 否 | 原币种的非负金额；不填表示尚未记录价格 |
| `currency` | 否 | `CNY`（默认）、`HKD`、`USD`、`JPY`、`EUR`、`GBP` |
| `price_cny` | 外币有价格时必填 | 人民币折算金额，供统计使用；导入不会联网查汇率 |
| `game_platform` | 否 | 游戏分类可填 `Nintendo` 或 `PC` |
| `game_content_type` | 否 | `本体`、`DLC`、`本体+DLC` |
| `game_edition` | 否 | `实体版`、`数字版`；PC 自动使用数字版，可省略 |
| `game_play_status` | 否 | `吃灰中`、`游玩中`、`已通关`、`全成就` |

四个游戏字段仅用于 `category` 为 `游戏` 的藏品。可省略的字段直接不写即可，不用写空字符串。外币示例：`"price": 10, "currency": "USD", "price_cny": 68`。

导入后在展柜点击藏品，再进入编辑，点封面区域添加图片并调整裁切。不要在清单中填写图片路径、ID 或账号信息。

这是新增藏品清单，与“导入备份”的 ZIP／旧 JSON 存档不同。每次导入都会生成新的藏品 ID，同名藏品也会新增；不要重复导入同一清单。文件校验失败时不会新增藏品；数据库单次批量写入全部成功或全部回滚。网络中断时 App 会按本次生成的 ID 查询确认；若仍无法确认，会刷新展柜并明确提示，先检查结果再重试。分类选项同步失败时，藏品仍已成功导入且保留分类名称，可在设置中补充分类，勿重复导入。

现有备份格式、表结构及数据均不变。
