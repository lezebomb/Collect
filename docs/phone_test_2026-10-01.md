# Dearshelf Android 真机验证与选择面板统一

日期：2026-10-01。设备：PLR110，Android 16 / API 36，1272 × 2800，560 dpi（约 363 × 800 逻辑尺寸）。在已登录的现有账号上通过 `adb install -r` 覆盖安装，没有清除应用数据。

本次以 `e7f368950d73116b0f96ea840f79f827ecf11d26` 为基础测试，并落实用户追加的底部选择面板要求。

## 本次 UI 调整

- 新增 `SelectionSheet` / `showSelectionSheet`，统一全宽、圆角、拖动柄、内边距及安全区。少量选项的基础高度约为屏幕三分之一；长列表自然展开，超过高度上限后内部滚动。宽度随屏幕方向变化。
- 新增 `SelectionOption`，统一圆角、选中状态和触控高度。文字根据宽度换行，字号跟随系统设置，不使用省略号截断选项。
- 接入统计分类 / 年份、展柜排序、封面来源、表单分类 / 游戏选项 / 货币、设置价格显示方式。
- 候选图片沿用较大的约 78% 高度，并与其他面板统一宽度及边距；标题、说明与候选列表一起滚动，避免长搜索词或大字号挤压图片区域。仍使用懒构建网格及原有图片缓存。
- 未新增依赖、网络查询或动画控制器；数据库、迁移、models、repositories、业务服务及备份格式未修改。
