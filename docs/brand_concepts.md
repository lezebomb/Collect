# Collect 品牌概念：明亮的私人收藏空间

> 后续状态：用户已选定 **Dearshelf**，抽象 Logo 探索已被南瓜猫窝睡猫的第二版插画替代。本文保留为概念阶段记录；最新选定设计见 [brand_selection.md](brand_selection.md)。

更新日期：2026-10-01。研究依据：[brand_research.md](brand_research.md)。

本轮用户要求已经明确：**只用英文品牌名；默认图标清新明亮；为自己的喜欢留位置，看到它们就开心。**

共同定位据此明确为 **Room for what you love**。这是工作性概念表达，不是最终名称。上一版的中文候选和暗色配色已撤下；本版保留三条值得深入的品牌路线，每条两个英文候选，供用户先选择方向。

本文件仍处于 Strategy / Concepts 阶段。没有更名、替换图标、修改 UI 或生成正式资源。下文色值和构图是探索建议，文字示意不是最终 Logo。

## 1. 品牌故事与情感重心

喜欢一件东西，并不需要复杂的理由。可能是一款玩过很久的游戏，也可能是一件好用的设备、一个旅行纪念物，或一个单纯觉得好看的小东西。

App 给它们留一个属于自己的位置，让用户打开时能轻松看见。开心来自这些收藏本身：它们是我喜欢的东西，它们都在这里。

品牌表达的重点是 **喜欢 → 有位置 → 被看见 → 开心**。陈列让它们被看见，记录让它们保留信息；两者都服务于这个私人空间。

工作性定位句：**A personal place for the things you love.**

可用于后续比较的语气：“Your favorites, right here.”。这些是解释方向的文案，不宣称名称或标语独占，也不将私人定位写成未经核实的安全技术承诺。

### 三个确定的设计判断

- **明亮且有清楚轮廓**：薄荷、蓝、暖黄、浅杏可以参与，默认 Icon 不使用大面积墨蓝、深绿、黑色或棕色底。
- **开心且现代**：靠开放构图、轻快颜色与用户收藏表达开心，不把品牌做成儿童角色或夸张笑脸。
- **亲近且可陈列**：一个被留出的空间和一件被安放的物形已经足够，不堆叠柜子、房子、字母、爱心和价格符号。

只用英文品牌名不要求现有 App 的正文改为英文。后续 UI 正文仍应清楚、可缩放，品牌字标与正文是不同角色。

## 2. 三条品牌路线与英文短名单

六个名称都基于常用英文词形成品牌合成词，属于命名探索，不是现成词典词。约定读法需在后续测试，不冒充已验证的英语母语者直觉。每条路线只保留两个能从同一概念解释的候选，不以数量代替判断。

| 候选 | 概念来源 / 读法 | 第一感受 | 符号核心 | 明亮配色重点 |
| --- | --- | --- | --- | --- |
| **Fondroom** | fond + room；FOND-room，8 个字母 | 喜欢的东西有自己的空间 | 开放包裹弧中留出一个物件位置 | 浅薄荷背景、清亮蓝曲线、少量暖黄物形 |
| **Fondplace** | fond + place；FOND-place，9 个字母 | 每件喜欢之物都有一个位置 | 宽而浅的承托弧与清楚留出的空位 | 同一薄荷 / 蓝 / 暖黄色系，物形更独立 |
| **DearShelf** | dear + shelf；DEER-shelf，9 个字母 | 喜欢的东西放在这里，容易看见 | 短承托与一个完整可见的物形 | 浅蓝背景、鲜明蓝支撑、柔和暖黄 |
| **DearPerch** | dear + perch；DEER-perch，9 个字母 | 喜欢的东西被安稳承托 | 小支点与略偏心、完整可见的物形 | 同一浅蓝 / 蓝 / 暖黄色系，支撑更短 |
| **Joyporch** | joy + porch；JOY-porch，8 个字母 | 一个明亮、开敞、让人开心的小地方 | 开敞的拱形入口，里面能看见一件物形 | 奶油黄背景、清亮蓝开口、浅杏物形 |
| **Dearporch** | dear + porch；DEER-porch，9 个字母 | 一个放着珍视之物的亲近小地方 | 相同开口母题，物形更靠内、留白更安静 | 同一奶油黄 / 蓝 / 浅杏色系，暖色更克制 |

三条路线分别强调安放、观看和轻快。符号分别从承托空间、陈列支点、开敞入口发展；同一路线中的两项名称也会影响物形位置、留白与字标，不能把名字与图形分开随意拼接。

按产品概念贴合度，**优先推荐路线一“为喜欢留位置”**，再比较路线二的直观和路线三的情绪。推荐顺序不是已替用户选定方向或名称。

### 初筛结果与边界

已执行普通网页、App Store、Google Play、GitHub 四渠道初筛，以及分词写法查询。六个候选在本次 CN / US App Store 接口中均未检出名称精确匹配；Google Play 网页索引未检出精确同名 App。GitHub 五个候选的仓库名称查询为 0；Dearporch 返回一个近似仓库 dearporchii，精确同名未检出。

普通网页仍有线索：Fondroom 出现在配件描述中；DearShelf 出现一个无法核实有效内容的 Beacons 路径；joyporch 被用作评论用户名，“Joy Porch”也用于装饰商品描述。Fond Place / Dear Porch 有日常语句或称呼语噪声；DearPerch 的隐喻理解待验证。不能由此断言名称、域名或账号空闲。范围、证据和排除项见 [研究文档第 8 节](brand_research.md#8-英文名称初筛从选定概念出发)。

本轮不注册名称，也不作商标结论。后续尤其需要验证读音、拼写、近似名称与第一产品联想。

## 3. 路线一：为喜欢留位置

### 品牌故事与两个名称候选

喜欢的东西有一处属于自己的地方，可以随时回来看看。重点是用户与收藏之间的归属关系，空间不必宏大，也不必是一座真实展馆。

- **Fondroom**：fond + room，表达喜爱与私人空间。空间感完整、亲近，是这条路线的优先候选；room 也可能产生住宿联想。
- **Fondplace**：fond + place，表达给喜欢之物留一个位置。比 room 更开放，不要求“房间”隐喻；代价是 place 更泛，分词搜索更容易混入普通语句。

两项都是以用户情感为出发点的合成词，不是为了给 Collect 添加后缀。不限定某类收藏，也不把记录、价格或整理效率写成主张。

### 视觉核心与 Icon

**一个开放、圆润的包裹弧，里面安放一个简单物形。**

- 只用两个主要形状：承托弧与物形。
- 弧不完全闭合，内部空白有足够宽度；“位置”不是密封箱。
- 物形略偏心，让关系自然；最终光学重心仍需保持稳定。
- 物形完整可见，不被曲线裹住大半；让“看到就开心”进入构图本身。
- 不依赖字母 U / C，也不加眼睛或小字；轮廓应区别于碗、钱包或笑脸。

关系示意，仅说明安放关系：

```text
         [简单物形]
        \          /
         \________/
          留出的位置
```

真正探索时要重新设计曲率与比例，不能把这段 ASCII 直接变成 Logo。

**名称与构图一起比较**：Fondroom 可测试稍深、较完整的承托空间；Fondplace 可测试较宽、较浅的弧，让“有一个位置”比“有一间房”更突出。两者沿用同一明亮色系，差别来自关系与比例。

### 配色建议

| 角色 | 色值 | 概念用途 |
| --- | --- | --- |
| 浅薄荷 | `#DFF7EF` | 默认 Icon 画布，保持整体明亮、清新 |
| 清亮蓝 | `#3E8DEB` | 承托弧与关键品牌形状，帮助轮廓清楚 |
| 暖黄 | `#FFD66F` | 小面积物形，表达被喜爱的温暖感 |

颜色不能负责全部识别。去色后仍须看清两个形状的关系；暖黄物形与薄荷背景的相邻边缘需要实际尺寸测试，若模糊，应调整色值或形状接触关系，不加复杂描边补救。

### Wordmark

优先测试小写 **fondroom / fondplace**：开放字腔、适度圆润的英文无衬线，中等字重。fondroom 的双 o 留白可呼应空间，fondplace 的词边界和较长横向节奏需单独调间距。保留正常字母阅读，不把字腔画成眼睛。

只探索少量端部或曲率处理，不使用泡泡字、极细字或复杂连字。不在当前阶段指定字体依赖或制作最终字标。

### UI 延续

继续以用户封面为主角，品牌颜色少量进入选中状态、添加入口和空状态。曲率与留白可以延续到已有圆角组件，不给每张卡片画一只容器。保存反馈保持直接，浏览已有收藏时安静、即时。

### 优点与风险

**优点**：最贴合“为喜欢留位置”；私人感明确，跨类别自然；清新图形能与现有圆润 UI 衔接。

**风险**：fond 的连接可能需要解释；room 可能偏住宿，place 可能太泛；普通包裹弧容易像收纳或钱包。优势必须通过读写与轮廓测试建立，不能仅靠品牌故事成立。

## 4. 路线二：让喜欢被看见

### 品牌故事与两个名称候选

喜欢的东西已经放在自己的位置上，打开就能看见。重点是观看带来的满足，陈列简单、清楚，收藏本身具有视觉吸引力。

- **DearShelf**：dear + shelf，表达珍视与陈列位置。最直观地提示“放在这里，容易看见”；需要避免被误解为只收藏书籍。
- **DearPerch**：dear + perch，把喜欢之物的安放位置比作一个小落脚处。承托感更轻，家具感较少；perch 容易产生鸟类联想，也更需要解释。

与路线一相比，它们把“看见”放在“空间归属”之前。不会因为候选里有 shelf 或 perch，就把业务扩展成书架或鸟类应用。

### 视觉核心与 Icon

**一条短而圆润的承托形，与一个清楚可见的物形。**

- 承托可以略弯而非硬直，让“位置”有亲近感。
- 物形与承托之间留下稳定、可读的间隙，物件是视觉主体。
- 不画木板纹理、架子立柱、柜门或分格；shelf 是陈列隐喻，不是写实图示。
- 不使用默认书本轮廓，不指定游戏、手机或手柄。
- 两个形状的宽度、错位与圆角共同形成识别，避免落成人物或通用展台图标。

```text
        [完整物形]

      [短、圆润的承托]
```

**名称与构图一起比较**：DearShelf 的承托可较宽，形成明确陈列关系；DearPerch 的支撑可更短、物形略偏心，强调轻量落脚处。两者都不使用书本或鸟的写实轮廓。

### 配色建议

| 角色 | 色值 | 概念用途 |
| --- | --- | --- |
| 浅蓝白 | `#E2F2FF` | 默认 Icon 画布，轻快、清楚 |
| 鲜明蓝 | `#408FEA` | 承托与主要品牌轮廓 |
| 柔暖黄 | `#FFCD64` | 小面积物形与品牌点缀 |

不使用上一版的墨蓝与金色组合，也不发展专业画廊的厚重感。形状的边缘差异仍需测试，色板不是已通过对比度验收的主题。

### Wordmark

比较 **DearShelf / DearPerch** 与小写写法：前者词边界清楚，后者更亲近。英文无衬线、中等字重、适度开放。DearShelf 的横向节奏可轻微呼应承托；DearPerch 的 p / e / r 间距优先保证可读，不把文字画成层板或鸟。

不能依靠首字母 D 加柜子建立识别，字标和独立符号应各自成立。

### UI 延续

封面下的名称与少量信息保持轻量、清楚的标注关系。维持紧凑收藏墙，品牌的“承托”由信息基线与间距体现，不为每个物件增加实体架子。默认明亮色彩给原图留出空间，不对收藏图片统一染色。

### 优点与风险

**优点**：收藏与观看的关系直观；语义容易解释；“看到它们就开心”不依赖写故事。

**风险**：shelf 容易让人想到读书或家具，perch 容易想到鸟；dear 也可能产生赠礼品牌联想；两个候选的词边界需读写测试。Beacons 路径线索未核实，不能声称相关账号可用。

## 5. 路线三：一个明亮的小地方

### 品牌故事与两个名称候选

自己的收藏组成一个明亮、亲近的小地方，打开时能看见喜欢之物。这条路线先传达轻快与开心，再提示整理和陈列。

- **Joyporch**：joy + porch，强调轻快、开敞的位置。情绪最直接；需要验证是否会被当作家居或情绪 App。
- **Dearporch**：dear + porch，强调这处小地方放着珍视的东西。语气更温和、喜爱对象更明确；同样需要验证 porch 的理解与读音。

porch 是门廊的空间隐喻：这里借的是小而开敞、容易看见的关系，不是公共社交空间。它在三条路线中理解成本最高；是否能自然解释成私人收藏，需要实际反馈，不能用长篇建筑故事说服用户。

### 视觉核心与 Icon

**一个简化、留有开口的拱形入口，里面能看见一件物形。**

- 以竖向拱形和侧边留白表达开敞，区别于路线一向上承托的弧、路线二水平支点。
- 不画完整房子、屋顶或门窗，入口是观看关系的抽象形状。
- 物形完整可见，入口边缘不能遮住它；在图标安全区内控制两个轮廓。
- 开心通过整体比例与明亮色彩表达，不额外增加笑脸或太阳射线。
- 最初仍以两个主要形状控制复杂度；不要因 porch 再叠加建筑元素。
- 需要检查是否像天气、家居或情绪 App，以及单色时是否仍有独特结构。

```text
       [留有开口的拱形]
             ↓
       [里面可见的物形]
```

这是关系描述，具体开口方向和物形位置待 Visual Exploration 测试，不代表符号已经完成。Joyporch 可让物形靠近开口、构图更开放；Dearporch 可略靠内、留白更安静。两者共用明亮暖色系，不把符号另画成爱心。

### 配色建议

| 角色 | 色值 | 概念用途 |
| --- | --- | --- |
| 奶油黄 | `#FFF0B8` | 默认 Icon 画布，让整体有明亮、轻快感 |
| 清亮蓝 | `#438FE8` | 拱形开口，形成清楚轮廓 |
| 浅杏 | `#FFA57C` | 小面积物形与温暖点缀 |

与路线一的薄荷、路线二的晴空蓝相比，这条路线更温暖。Dearporch 可减少浅杏面积，让语气更安静；不改变明亮默认底色。避免把所有颜色进一步粉化，浅背景与物形的色相 / 明度差异必须在真实尺寸下可读。

### Wordmark

优先测试小写 **joyporch / dearporch**，保持 p、o 等字母的开放空间，字重适中。joyporch 可比较稍轻快的字距，dearporch 以自然词边界为先。温和来自比例和间距，不使用儿童式圆泡字体或强连笔。porch 的读音是重点验证项。

### UI 延续

小面积暖色可以进入已有添加入口或空状态，收藏照片保留自己的颜色。语气比其他两项更轻快，但不增加奖励、角色或打卡。日常浏览应让人先看收藏，而不是先看一块巨大品牌插画。

### 优点与风险

**优点**：最直接表达开心；明亮暖色有亲近感；没有把名字锁死在某一类收藏。

**风险**：porch 对部分用户不熟悉，可能联想到家居或公开门廊；合成词的语义需要验证；Joy Porch 也用于装饰商品描述，Dearporch 有近似仓库名，分词搜索会有噪声。名称若需要大量解释，应降低优先级。

## 6. 三条路线的区别与建议

| 维度 | 路线一：为喜欢留位置 | 路线二：让喜欢被看见 | 路线三：明亮的小地方 |
| --- | --- | --- | --- |
| 更强调什么 | 喜欢在这里有自己的空间 | 喜欢的收藏容易被看见 | 看见喜欢之物时的轻快、开心 |
| 名称短名单 | Fondroom / Fondplace | DearShelf / DearPerch | Joyporch / Dearporch |
| 主要语义难点 | room 的住宿联想、place 较泛 | shelf 的家具联想、perch 的鸟类联想 | porch 的理解与发音 |
| 图形难点 | 包裹弧如何区别于普通容器 | 承托与物形如何有独特比例 | 开敞入口如何避免房屋 / 浏览器图标 |
| 配色感受 | 薄荷与蓝，清新 | 蓝与暖黄，清楚 | 奶油黄与蓝，温暖明亮 |
| 对当前 UI 的延续 | 适度曲率与留白 | 轻量陈列与清楚标注 | 小面积暖色与直接轻快的语气 |

三条路线共用同一产品定位，不产生三套功能。**优先推荐路线一**，因为它最直接承接“为喜欢留位置”；路线二的陈列更直观，路线三的情绪更明亮。用户仍可先选择哪一种表达更像自己的 App，再收敛名称、符号、配色与字标。

## 7. 后续验证与落地边界

品牌路线、名称与图标尚未最终选定。下一阶段顺序：

1. 用户先选择品牌路线，随后比较该路线内两个英文候选的读写、记忆与第一产品联想；不先解释长故事诱导答案。
2. 方向确认后单独开展 Visual Exploration，对短名单做少量黑白构图与明亮配色探索，与英文 Wordmark 放在一起评估。
3. 在 20 / 24 / 32 / 48 / 64 px 内部检查样张、Android 不同 Mask、单色主题与 Apple 多外观中验证同一轮廓。黑白版是识别测试，不是另推暗色默认品牌。
4. 继续核查名称的近似产品、地区商店、域名与社交账号；必要时另行做专业商标核查。现阶段的未检出不能替代这些工作。
